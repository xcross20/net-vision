# Stock Token payment policy

US requests: Stock Tokens `REGION_RESTRICTED`. Unknown country: `REGION_UNKNOWN`. No executable quote.

Non-US: jurisdiction ALLOWED, but assets remain `DISABLED` until that ticker’s own route + live E2E PASS. Enabling NVDA does not enable AAPL.
