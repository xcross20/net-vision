## Development status

These documents intentionally describe future architecture. They do not authorize implementation during the current Net Vision launch freeze unless a later work order explicitly opens an intelligence track.

Current marketplace reliability, transaction safety and launch readiness remain higher priority.

## External research seed

The architecture was informed in part by reviewing the public MIT-licensed `tomismeta/netstack` research skill. Helix should treat external research packages as pinned, provenance-preserved knowledge inputs, not mutable runtime authorities. Time-sensitive facts must be independently refreshed.
